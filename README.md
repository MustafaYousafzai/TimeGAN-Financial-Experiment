## 1. Project Overview
This project serves as the empirical validation component for our survey paper, *"Capturing Temporal Dynamics in Time Series Data with Generative Adversarial Networks."*

We implemented and trained a **Time-series Generative Adversarial Network (TimeGAN)** on real-world S&P 500 financial data. The goal was to validate whether adversarial learning can capture the non-stationary temporal dynamics and structural manifold of high-volatility financial regimes.

## 2. Methodology & Architecture
The model utilizes a GRU-based architecture comprising four distinct networks trained via a multi-phase loss function:
1.  **Embedding Network:** Compresses temporal features into a latent space.
2.  **Recovery Network:** Reconstructs features from latent codes (Autoencoder).
3.  **Generator:** Generates synthetic latent codes from random noise.
4.  **Supervisor:** Enforces temporal causality ($t \to t+1$) in the latent space.

* **Training Schedule:** 200 Joint Epochs (Optimized for regime separation).
* **Batch Size:** 256.
* **Dataset:** S&P 500 Stock Data (2013-2018), preprocessed with sliding windows ($T=24$).

## 3. Repository Contents

## 4. How to Reproduce Results
The code is optimized for **Google Colab** (T4 GPU).

1.  Open `TimeGAN_SP500_Experiment.ipynb` in Google Colab.
2.  Upload the `all_stocks_5yr.csv` dataset (Available on Kaggle: [S&P 500 Dataset](https://www.kaggle.com/datasets/camnugent/sandp500)) to the Colab runtime.
3.  Run all cells sequentially.
4.  The notebook will automatically:
    * Train the model.
    * Generate the visualization plots.
    * Calculate the predictive score.
    * Save the `synthetic_sp500.csv` file.

## 5. Key Results
* **Predictive Utility:** The model achieved a Mean Absolute Error (MAE) of **$3.66** on the Train-on-Synthetic-Test-on-Real (TSTR) protocol.
* **Structural Fidelity:** t-SNE analysis confirms that the synthetic data manifold significantly overlaps with the real data distribution, capturing distinct market volatility regimes.
